# Proxy request diagnostics

The web container writes structured request records to stdout. Each record includes
method, normalized path, status, response size, duration, upstream status and timing,
and a request reference. Query strings, referrers and request bodies are omitted.
API responses retain their application `X-Request-ID`; failures generated by nginx,
such as an oversized upload or unavailable upstream, receive a proxy-generated ID
in both the response header and the structured record. Internal API connection
attempts have a five-second budget; report/export response timeouts remain
configured separately.

nginx's built-in HTTP error messages include the original request line, which can
expose OIDC authorization codes or analyst search terms. Their format cannot be
redacted, so HTTP request-context error output is disabled. Startup and master
process diagnostics still go to stderr. This deliberately trades detailed nginx
request-error prose for sanitized status/timing records. Diagnose upstream errors
using those records, API health and application logs. Reproduce problems requiring
raw nginx diagnostics in an isolated environment with synthetic requests.

From the repository root, verify a running isolated Compose stack:

```sh
python3 scripts/verify_access_log_privacy.py --base-url http://localhost:3000 \
  --container "$(docker compose ps -q web)" --container "$(docker compose ps -q api)"
```

This checks both a correlated health request and an oversized request rejected by
the proxy. To exercise an upstream failure, stop the API in that disposable stack,
run the following check, and restart the API afterward. The verifier itself does
not start or stop containers.

```sh
docker compose stop api
python3 scripts/verify_access_log_privacy.py --base-url http://localhost:3000 \
  --upstream-unavailable --container "$(docker compose ps -q web)"
docker compose start api
```

A successful run prints `Log privacy passed`. These checks use synthetic values
and inspect only the containers supplied on the command line.
