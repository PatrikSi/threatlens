# Dashboard Page

## Purpose

The dashboard is the primary triage workspace for RSS intelligence and alert matches.

## Top Controls

- Save current dashboard state as a named view.
- Load previously saved views.
- Manage views (export JSON, import JSON, delete existing views).
- Add windows from a dropdown:
  - RSS Feed Window
  - Alerts Window

## Window Layout

Each window supports:

- Drag to move (desktop layouts).
- Corner resize handle (desktop layouts).
- Snap presets:
  - Full
  - Left half
  - Right half
  - Top-left quarter
  - Top-right quarter
  - Bottom-left quarter
  - Bottom-right quarter

Snapped windows are flush to workspace edges to remove side/bottom margins.

## RSS Window Features

- Feed chip filters.
- Tag chip filters.
- Search.
- Time range and sort.
- Read/star filters.
- Expanded/compact view mode.
- Item expansion with summary, full article text, and notes.
- Triage controls: read/unread, star/unstar, note updates.

## Alerts Window Features

- Filter by alert categories.
- Filter by configured alert interests.
- Search, time range, and sort.
- Matched item list with matched alert labels.
