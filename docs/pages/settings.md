# Settings Page

## Purpose

Settings centralizes account and administration controls.

## Sections

- Overview (role capabilities)
- Account
- API Tokens
- Users (admin only)
- Audit Logs (admin only)

## Role Capability Summary

- Admin: full platform administration.
- Analyst: feed and triage operations, no user/audit administration.
- Viewer: read-only intelligence operations with personal account/token access.
